# TaskFlow — Project Roadmap & Technical Status

## 🚀 1. Выполненные этапы (Completed)

### 1.1 Архитектура и Базовый UI
- [x] Авторизация, регистрация и ротация JWT-токенов (`/auth/*`).
- [x] Профиль пользователя с редактированием данных (`/profile`).
- [x] Вкладка безопасности и смены пароля в профиле (`POST /auth/change-password`).
- [x] Темная и светлая тема оформления через `next-themes`.
- [x] Оконная система в стиле macOS (`MacModal`):
  - **Красная кнопка**: закрытие с эффектом плавного уменьшения и размытия (`scale-95 blur-sm`).
  - **Желтая кнопка**: закрытие со специальной анимацией сжатия (`squeeze compression`).
  - **Зеленая кнопка**: переключение между стандартным размером и полноэкранным режимом (`maximizedWidth`).
  - Увеличенные тач-зоны (`size-4 sm:size-3`) и видимые глифы на смартфонах/планшетах.
- [x] Адаптивная ширина контейнеров (`max-w-[1400px]`) на всех ключевых страницах.

### 1.2 Хедер и Навигация (`AuthedHeader`)
- [x] Интеллектуальный селектор рабочих пространств:
  - Автоматическое определение активного пространства по URL (`pathSegments[0]`).
  - Режим «Все пространства» при нахождении на главной странице `/`.
  - Вкладка «Проекты» отображается **только** при нахождении внутри конкретного воркспейса.
- [x] Создание пространства через модалку без 404-переходов на `workspace/new`.
- [x] Семантические цветные индикаторы macOS (`#007aff` синий для пространств, `#27c93f` зеленый для создания).

### 1.3 Управление Проектами (`ProjectsView`)
- [x] Список проектов с поиском, фильтрацией (Активные, Все, Архив) и сортировкой.
- [x] Модалки создания (`CreateProjectModal`) и редактирования (`EditProjectModal`) на базе `MacModal`.
- [x] Карточки проектов с переходом в проект по клику на всю площадь карточки.
- [x] Меню карточки проекта с точками macOS (редактирование, архивация/восстановление, удаление).

### 1.4 Канбан-доска и Задачи (`KanbanBoard`)
- [x] Полная модуляризация Канбана (сокращение с 1000+ строк до ~350 строк):
  - `KanbanCard.tsx`: Карточка задачи с приоритетом, исполнителем и сменой статуса.
  - `CreateIssueModal.tsx`: Отдельная модалка создания задачи.
  - `IssueDetailModal.tsx`: Отдельная модалка просмотра и редактирования задачи.
  - `kanbanConstants.tsx`: Константы, иконки жизненных циклов и цвета приоритетов.
- [x] Защита от ошибок `null`/`undefined` при чтении данных исполнителей (`primaryAssignee`).
- [x] Мгновенное открытие модалки создания задачи по клику на «+» в любой колонке с предвыбранным статусом.

### 1.5 Обсуждения, Метки и Связи Задач
- [x] Древовидные обсуждения к задачам (`IssueComments.tsx`, `POST/GET/PATCH/DELETE /comments/*`):
  - Иерархия ответов (`parent_comment_id`).
  - Редактирование и удаление собственных комментариев.
  - Человеко-ориентированное относительное время («только что», «5 мин.», и т.д.).
- [x] Управление метками проекта и задач (`IssueLabels.tsx`, `labelApi.ts`):
  - Прикрепление и открепление меток от задачи.
  - Создание новых меток с палитрой аккуратных нейтральных и пастельных цветов.
  - Отображение цветных меток прямо на карточках канбан-доски (`KanbanCard.tsx`).
- [x] Зависимости и связи задач (`IssueRelations.tsx`, `relationApi.ts`):
  - 4 типа связей: «Блокирует» (`blocks`), «Блокируется» (`blocked_by`), «Связана с» (`relates_to`), «Дублирует» (`duplicates`).
  - Интерактивный селектор связанных задач и удаление связей.
- [x] Вкладки в окне задачи `IssueDetailModal.tsx` («Параметры», «Обсуждение», «Связи») в стиле нативных окон macOS.
